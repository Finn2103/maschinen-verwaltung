# UML

Dokumentation über UML ist Vorgabe. Diagramme als Quelltext ablegen
(PlantUML oder Mermaid), damit Änderungen im Diff sichtbar sind, gerenderte
Bilder nur zusätzlich.

| Diagramm | Wofür | Status |
| --- | --- | --- |
| Use-Case | Akteure und ihre Anwendungsfälle (Kunde, Verleiher, Buchhaltung, Technik) | offen |
| Klassendiagramm | Objektorientierter Entwurf, Pflicht im Hinblick auf die Abschlussprüfung | offen |
| Sequenzdiagramm | Kritische Abläufe: Reservierung, Rechnungsstellung, Zahlung | offen |
| Komponentendiagramm | Proxy, Authelia, Kong, Supabase, PostgreSQL, Object Storage, Mail | offen |
| Aktivitätsdiagramm | Wartungsprognose, Altdatenübernahme aus Excel | offen |
