vorstellen kann und im Review nachvollziehbar ist, dass die Oberfläche entworfen und nicht
nebenbei zusammengesetzt wurde.

## Regel für diese Entwürfe

**Jeder Bildschirm ist an ein Akzeptanzkriterium gebunden**, und über jedem steht, welches.
Was im Backlog nicht steht, wird nicht entworfen — sonst täuschen die Mockups einen Umfang
vor, den niemand zugesagt hat.

Umgekehrt gilt: Kriterien, die nur als Zustand sichtbar werden, brauchen einen eigenen
Bildschirm. Deshalb gibt es „kein Treffer im Zeitraum" und „Zeitraum belegt" als eigene
Entwürfe — ohne sie wäre das schwierigste Kriterium von #1 unsichtbar.

## Barrierefreiheit

Die Entwürfe zeigen sichtbare Labels an jedem Feld, Fehlermeldungen am betroffenen Feld
und einen sichtbaren Fokusrahmen. Das sind Akzeptanzkriterien aus #1, keine Stilfragen.

An diesen fertigen Bildschirmen lässt sich die **ISO-9241-Checkliste** festlegen, die laut
Definition of Done für alle Oberflächen gilt — am Entwurf ist das deutlich leichter als am
leeren Blatt.
