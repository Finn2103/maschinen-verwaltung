# Scrum

Lehrkräfte = Product Owner. Wir = Entwicklungsteam. Scrum Master: Finn2103.
Sprints à 2–3 Wochen, Review und Retrospektive in Präsenz.
Pro Sprint eine Note je Person — die Fachnote besteht zu 50 % aus dem Projekt.

| Datei | Inhalt | Status |
| --- | --- | --- |
| `projektstart.html` | Kickoff-Übersicht zum Vorstellen im Team — Quelle des geteilten Artefakts | laufend |
| `po-klaerung.md` | Offene Fragen an die Lehrkräfte als Product Owner | offen |
| `backlog-neufassung.md` | Neugefasste Items mit Begründung je Änderung | Vorschlag fürs Refinement |
| `definition-of-done.md` | Wann ein Item fertig ist | Entwurf |
| `sprint-<n>/review.md` | Was im Review gezeigt und abgenommen wurde | pro Sprint |
| `sprint-<n>/retro.md` | Was wir beibehalten, was wir ändern | pro Sprint |

## Termine

- **Donnerstag** — reiner Projekttag, zunächst in Präsenz
- **Freitag** — Projektstunden plus Wirtschaftsunterricht
- **Abgabe** — Freitag 11.12.2026, 8. Stunde
